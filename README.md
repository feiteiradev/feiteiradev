# Hey, I'm Pedro 👋

> *I stopped being "just a developer" the moment AI removed the wall between my ideas and the software that defines them.*

I'm a **builder**. I ship autonomous systems, AI-augmented products, and personal tools that solve real problems — most of them mine first.

My background is software engineering (Python, TypeScript, FastAPI, React Native), but what actually drives me now is the intersection of **AI tooling × automation × product thinking**. I'm always researching, always testing the next model, agent framework, or infra pattern. Productivity isn't a habit for me — it's an obsession.
